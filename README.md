# MeraTurn - Digital Queue Management Platform 🎯

A modern, premium, responsive frontend UI for a smart digital queue management startup platform.

## ✨ Features

- 🏥 **Multi-Service Support** - Hospitals, Clinics, Banks, Schools, Government Offices
- 📱 **Mobile-First Design** - Optimized for all devices
- 🎨 **Premium UI/UX** - Clean, modern, healthcare-inspired interface
- ⚡ **Smooth Animations** - Framer Motion powered transitions
- 🔔 **Real-Time Updates** - Live queue tracking (mock)
- 📊 **Complete User Flow** - From landing to token generation
- 🎯 **Production Ready** - Investor/demo ready prototype

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

Visit `http://localhost:5173` and click "Book Now" to start!

## 📱 User Journey

1. **Landing** → Compelling hero with CTA
2. **Login** → Mobile OTP authentication
3. **Home** → Search, categories, nearby organizations
4. **Organization** → Details, services, departments
5. **Booking** → Multi-step booking flow
6. **Token** → Digital token with QR code
7. **Queue** → Live tracking with progress
8. **Notifications** → Alerts and reminders
9. **Bookings** → Appointment management
10. **Profile** → User settings and history

## 🛠️ Tech Stack

- **React 19** - Latest React features
- **TypeScript** - Type-safe development
- **Tailwind CSS v4** - Utility-first styling
- **ShadCN UI** - Premium components (Nova preset)
- **Framer Motion** - Smooth animations
- **Lucide React** - Beautiful icons
- **React Router DOM** - Client-side routing
- **Vite** - Lightning-fast build tool
